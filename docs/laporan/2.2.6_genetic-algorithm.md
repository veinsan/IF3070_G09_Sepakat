### 2.2.6. Genetic Algorithm

*Genetic Algorithm* (GA) adalah algoritma pencarian yang mengolah sekumpulan *state* sekaligus. Kumpulan itu disebut populasi, dan setiap *state* di dalamnya disebut individu. Populasi baru (generasi berikutnya) dibentuk dari individu yang lebih baik melalui seleksi, *crossover* (persilangan dua induk), dan mutasi. Modul *Genetic Algorithm* pada CARGO mengacu pada materi kuliah [5] dan berada di `src/search/genetic_algorithm.py`.

**Representasi.** Kromosom (representasi satu individu) adalah daftar posisi kendaraan yang sama dengan representasi *state* pada *Hill-Climbing* dan *Simulated Annealing*. Setiap gen (satu elemen kromosom) mewakili satu kendaraan dengan urutan indeks tetap. Nilainya adalah `None` jika kendaraan berada di luar kapal atau `(kapal, x, y, orientasi)` jika berada di dalam. Karena representasinya sama, GA memakai fungsi *objective*, penalti, dan *delta evaluation* yang sama dengan algoritma lain.

**Alur satu generasi.** Populasi awal berisi `population_size` *state* acak. Setiap generasi berjalan sebagai berikut.

1. Urutkan populasi berdasarkan nilai *objective*, lalu salin langsung dua individu terbaik ke populasi baru (*elitism*).
2. Bentuk roda *roulette* dari nilai *fitness* (nilai kelayakan individu untuk dipilih) seluruh populasi.
3. Pilih dua induk dengan dua kali putaran roda.
4. Dengan peluang p_c, lakukan *crossover* satu titik untuk menghasilkan dua anak. Jika *crossover* tidak dilakukan, anak adalah salinan induk.
5. Mutasikan setiap anak dengan peluang p_m.
6. Ulangi langkah 3–5 sampai ukuran populasi baru sama dengan ukuran populasi lama.

Satu iterasi pada GA berarti satu generasi.

#### 2.2.6.1. *Fitness* dengan *Windowing*

Seleksi *roulette wheel* membutuhkan nilai *fitness* yang positif, padahal nilai *objective* dapat negatif karena penalti. Oleh karena itu, CARGO memakai *windowing*, yaitu menggeser semua nilai terhadap nilai terburuk dalam populasi:

fitᵢ = fᵢ − minⱼ fⱼ + ε,

dengan:

- fitᵢ = *fitness* individu ke-i;
- fᵢ = nilai *objective* individu ke-i (termasuk penalti);
- minⱼ fⱼ = nilai *objective* terburuk dalam populasi generasi tersebut;
- ε = konstanta positif kecil, yaitu `GA_EPSILON` = 1.

Penambahan ε menjamin peluang terpilih individu terburuk tidak bernilai nol. Pilihan *windowing* dan nilai ε merupakan keputusan implementasi CARGO sendiri.

```python
def roulette_cumulative(objectives: Sequence[float], epsilon: float = GA_EPSILON) -> list[float]:
    ...
    worst = min(objectives)
    return list(itertools.accumulate(f - worst + epsilon for f in objectives))
```

#### 2.2.6.2. Seleksi *Roulette Wheel*

Pada *roulette wheel selection*, peluang individu ke-i terpilih sebanding dengan *fitness*-nya:

P(i) = fitᵢ / (fit₁ + fit₂ + … + fit_M),

dengan M adalah ukuran populasi. Roda dibentuk sekali setiap generasi sebagai jumlah kumulatif *fitness* Cᵢ = fit₁ + fit₂ + … + fitᵢ. Setiap putaran mengambil bilangan acak r yang seragam di antara 0 dan C_M, lalu memilih individu pertama dengan Cᵢ ≥ r. Pencarian indeks tersebut memakai *binary search* (pencarian biner) melalui modul `bisect`.

```python
def spin(cumulative: Sequence[float], rng: random.Random) -> int:
    ...
    r = rng.uniform(0, cumulative[-1])
    return min(bisect.bisect_left(cumulative, r), len(cumulative) - 1)
```

Fungsi `min` mencegah indeks melewati batas jika r tepat sama dengan C_M akibat pembulatan bilangan pecahan.

#### 2.2.6.3. *Crossover* Satu Titik

Untuk dua induk a dan b dengan n gen, dipilih titik potong acak c dengan 1 ≤ c ≤ n − 1. Anak pertama berisi gen a sebelum titik potong dan gen b sesudahnya; anak kedua sebaliknya:

anak₁ = a[0..c−1] + b[c..n−1]

anak₂ = b[0..c−1] + a[c..n−1]

*Crossover* dilakukan dengan peluang p_c = 0,8. Anak dibentuk dari salinan induk sehingga induk tidak berubah. Hanya gen yang berbeda yang diganti agar biaya evaluasi sebanding dengan banyaknya gen yang berubah.

```python
def crossover(a: State, b: State, cut: int) -> tuple[State, State]:
    ...
    child1, child2 = a.copy(), b.copy()
    for i in range(cut, n):
        pa, pb = a.placement(i), b.placement(i)
        if pa != pb:
            child1.set(i, pb)
            child2.set(i, pa)
    return child1, child2
```

Karena gen berisi koordinat, menggabungkan dua induk yang sama-sama *feasible* dapat menghasilkan anak dengan kendaraan bertumpuk. Anak seperti itu tetap masuk populasi dan dikenai penalti.

#### 2.2.6.4. Mutasi

Mutasi dilakukan pada setiap anak dengan peluang p_m = 0,2. Bentuk mutasinya adalah satu *random neighbor* yang sama dengan SA: memindahkan satu kendaraan (termasuk ke luar atau ke dalam kapal), menukar dua kendaraan, atau mengubah orientasi.

```python
def mutate(state: State, rng: random.Random) -> None:
    state.apply(random_neighbor(state, rng))
```

#### 2.2.6.5. *Elitism*

*Elitism* meloloskan sejumlah individu terbaik ke populasi baru apa adanya, tanpa *crossover* dan mutasi. CARGO memakai `GA_ELITISM` = 2 sehingga nilai *objective* maksimum populasi tidak pernah turun antargenerasi. Nilai *objective* individu elit tidak dihitung ulang. Penggunaan *elitism* merupakan heuristik tambahan pada CARGO. Potongan kode berikut adalah isi satu generasi.

```python
for generation in range(1, iterations + 1):
    ranked = sorted(range(population_size), key=objectives.__getitem__, reverse=True)
    offspring = [population[i] for i in ranked[:elitism]]
    offspring_objectives = [objectives[i] for i in ranked[:elitism]]
    cumulative = roulette_cumulative(objectives, epsilon)

    while len(offspring) < population_size:
        a, b = population[spin(cumulative, rng)], population[spin(cumulative, rng)]
        if n > 1 and rng.random() < p_crossover:
            children = crossover(a, b, rng.randint(1, n - 1))
            crossovers += 1
        else:
            children = a.copy(), b.copy()
        for child in children:
            if len(offspring) == population_size:
                break
            if rng.random() < p_mutation:
                mutate(child, rng)
                mutations += 1
            offspring.append(child)
            offspring_objectives.append(child.objective)
            if incumbent.observe(child):
                best_generation = generation
            evaluations += 1
```

#### 2.2.6.6. Parameter dan Keluaran

Tabel 2.2.6.1 Parameter *Genetic Algorithm* (`src/config.py`)

| Parameter | Nilai | Keterangan |
|---|---|---|
| `GA_POPULATION` | 100 | Ukuran populasi kontrol |
| `GA_ITERATIONS` | 1.000 | Banyak generasi kontrol |
| `GA_ITERATION_VARIANTS` | 300; 1.000; 3.000 | Variasi banyak generasi (populasi tetap 100) |
| `GA_POPULATION_VARIANTS` | 50; 100; 200 | Variasi ukuran populasi (generasi tetap 1.000) |
| `GA_P_CROSSOVER` (p_c) | 0,8 | Peluang *crossover* |
| `GA_P_MUTATION` (p_m) | 0,2 | Peluang mutasi setiap anak |
| `GA_ELITISM` | 2 | Banyak individu elit |
| `GA_EPSILON` (ε) | 1 | Konstanta *windowing* |

Sesuai spesifikasi, eksperimen hanya mengubah ukuran populasi dan banyak generasi; parameter lain tetap.

Fungsi `genetic_algorithm` mengembalikan `RunResult` dengan ketentuan berikut.

- *State* awal (`initial_state`) adalah individu terbaik pada populasi awal, karena GA tidak berangkat dari satu *state* saja.
- *State* akhir (`final_state`) adalah individu *feasible* terbaik yang ditemukan pada generasi mana pun.
- Riwayat nilai *objective* maksimum (`history["objective"]`) dan rata-rata populasi (`history["mean"]`) dicatat setiap generasi untuk membuat plot.
- Banyak evaluasi dihitung dari populasi awal ditambah semua anak baru.
